# 示例特效

四个可直接用于舞台和观众区的定义。保存到 `config/astrorbitsparticle/effects/<name>.json`，执行 `/astrorticle reload` 后用 `/astrorticle effect play <name>` 播放。

## 爱心飘动

缓慢上浮、左右摆动，寿命末尾收缩并淡出。`stream` 让爱心持续补充，不会一次全出。

```json
{
  "style": "astrorbitsparticle:fountain",
  "duration": 10,
  "loop": true,
  "emission": {"mode": "stream", "count": 60, "lifetime": 7, "lifetimeJitter": 0.35, "window": [0, 10]},
  "physics": {"gravity": [0, 0.25, 0], "drag": 0.15},
  "appearance": {
    "sprite": "minecraft:heart",
    "size": 0.35,
    "sizeJitter": 0.25,
    "blend": "alpha",
    "sizeByAge": [[0, 0.5], [0.15, 1], [0.8, 1], [1, 0]],
    "alphaByAge": [[0, 0], [0.1, 1], [0.75, 1], [1, 0]],
    "colorByAge": [[0, "#FFD1E8"], [1, "#FF6FAE"]]
  },
  "visibility": {"requireScene": false, "viewDistance": 64},
  "params": {"axis": [0, 1, 0], "spread": 30, "speed": 1.4, "speedJitter": 0.5, "nozzleRadius": 3}
}
```

## 向前飞的爱心

一次播放发射 4 颗爱心，朝 `axis` 方向飞出，途中上下摆动，出生后快速放大，末尾轻微鼓起再快速缩小消失。出生位置与飞行方向都带随机量。

```json
{
  "style": "astrorbitsparticle:radial_burst",
  "duration": 3.2,
  "loop": false,
  "emission": {"mode": "burst", "count": 4, "lifetime": 3.2, "lifetimeJitter": 0},
  "physics": {"gravity": 0, "drag": 0},
  "appearance": {
    "sprite": "minecraft:heart",
    "size": 0.8,
    "sizeJitter": 0.18,
    "blend": "alpha",
    "sizeByAge": [[0, 0.1], [0.08, 1], [0.78, 1], [0.88, 1.12], [1, 0]],
    "alphaByAge": [[0, 0], [0.05, 1], [0.82, 1], [0.92, 1], [1, 0]],
    "colorByAge": [[0, "#FFD1E8"], [0.7, "#FF8FC0"], [1, "#FF4F9A"]]
  },
  "visibility": {"requireScene": false, "viewDistance": 64},
  "params": {
    "axis": [0, 0, 1],
    "cone": 20,
    "speed": 4.5,
    "speedJitter": 0.12,
    "originJitter": 0.45,
    "bobAmplitude": 0.25,
    "bobPeriod": 1.3
  }
}
```

- `emission.count` 控制每次发射的爱心数，这里取 4，可在 3–5 之间调；`mode=burst` 让它们同时出生。
- `axis` 是飞行方向，按场景里的"前"改；`cone` 是左右与上下方向共用的随机半角。
- 尺寸动画都在 `appearance.sizeByAge`：`0→0.08` 快速放大到正常尺寸，`0.88` 处到 1.12 倍，最后缩到 0。
- `bobAmplitude`/`bobPeriod` 控制摆动幅度与周期；`originJitter` 控制出生点随机范围。

## 火焰喷射 + 烟花

火焰用喷泉向上喷，结束时用 `subEffect` 触发一次球状烟花。

### stage_flame.json

```json
{
  "style": "astrorbitsparticle:fountain",
  "duration": 3,
  "loop": true,
  "subEffect": "astrorbitsparticle:stage_firework",
  "subEffectTrigger": "end",
  "emission": {"mode": "stream", "count": 160, "lifetime": 1.4, "lifetimeJitter": 0.3, "window": [0, 3]},
  "physics": {"gravity": [0, -2.5, 0], "drag": 0.4},
  "appearance": {
    "sprite": "minecraft:flame",
    "size": 0.45,
    "sizeJitter": 0.35,
    "blend": "additive",
    "sizeByAge": [[0, 1], [0.6, 0.8], [1, 0]],
    "alphaByAge": [[0, 0.9], [0.6, 0.7], [1, 0]],
    "colorByAge": [[0, "#FFF2B0"], [0.5, "#FFB340"], [1, "#FF5A1F"]]
  },
  "visibility": {"requireScene": false, "viewDistance": 96},
  "params": {"axis": [0, 1, 0], "spread": 10, "speed": 7, "speedJitter": 0.25, "nozzleRadius": 1.2}
}
```

### stage_firework.json

```json
{
  "style": "astrorbitsparticle:spherical_burst",
  "duration": 1.6,
  "emission": {"mode": "burst", "count": 320, "lifetime": 1.6, "lifetimeJitter": 0.2},
  "physics": {"gravity": [0, -6, 0], "drag": 0.2},
  "appearance": {
    "sprite": "minecraft:glitter_3",
    "size": 0.35,
    "sizeJitter": 0.4,
    "blend": "additive",
    "sizeByAge": [[0, 1], [1, 0.2]],
    "alphaByAge": [[0, 1], [0.7, 1], [1, 0]],
    "colorByAge": [[0, "#FFFFFF"], [0.4, "#FFE08A"], [1, "#FF7A2F"]]
  },
  "visibility": {"requireScene": false, "viewDistance": 128},
  "params": {"speed": 9, "fill": 0, "shellJitter": 0.15, "flatten": 1}
}
```

## 稀疏流星雨

覆盖约 240×140×240 的范围，慢速斜落，靠 `stretch` 拉出尾迹，粒子很少，适合大场景远景。

```json
{
  "style": "astrorbitsparticle:rain",
  "duration": 12,
  "loop": true,
  "emission": {"mode": "stream", "count": 70, "lifetime": 5, "lifetimeJitter": 0.6, "window": [0, 12]},
  "physics": {"gravity": [0, 0, 0], "drag": 0},
  "appearance": {
    "sprite": "minecraft:glitter_3",
    "size": 0.7,
    "sizeJitter": 0.3,
    "blend": "alpha",
    "stretch": 0.06,
    "sizeByAge": [[0, 0.8], [0.2, 1], [1, 0.4]],
    "alphaByAge": [[0, 0], [0.1, 0.8], [0.8, 0.6], [1, 0]],
    "colorByAge": [[0, "#EAF6FF"], [1, "#7FB8FF"]]
  },
  "visibility": {"requireScene": false, "viewDistance": 256},
  "params": {
    "direction": [0.45, -1, 0.25],
    "speedRange": [18, 26],
    "area": [240, 140, 240],
    "trailCount": 3,
    "trailSpread": 0.12,
    "wrap": true
  }
}
```

## 调参提示

- 爱心太密就降 `count`，太大就降 `size`，消失太突然就把 `alphaByAge` 末段拉长。
- 火焰和烟花都是 additive，重叠处会过曝；需要柔和一点就改 `alpha` 并降低 `size`。
- 流星雨想更稀就降 `count`，想更亮就提高 `alphaByAge` 中段，`stretch` 决定尾迹长度。
