# 配置文件

## config.json

路径 `config/astrorbitsparticle/config.json`，两端各自读取，缺失时写入默认值。修改后需要重启。

| 键 | 默认 | 范围 | 说明 |
| --- | --- | --- | --- |
| `maxParticlesPerEffect` | 8192 | 1 到 1048576 | 单个特效的粒子上限，定义里的 `emission.count` 超过时按上限截断 |
| `maxVisibleParticles` | 20000 | 1 到 1048576 | 客户端一帧内计划的粒子总数上限，超出时提高采样步长 |
| `maxVisibleEffects` | 64 | 1 到 1024 | 客户端一帧内渲染的特效数量上限，按距离保留最近的 |
| `frameBudgetMs` | 4.0 | 0.5 到 50 | 客户端单帧采样预算（毫秒），连续超出时自动提高步长 |

`maxVisibleParticles`、`maxVisibleEffects`、`frameBudgetMs` 只在客户端生效；`maxParticlesPerEffect` 只在服务端解析定义时生效。

## 数据包定义

特效定义可以随数据包分发，路径 `data/<namespace>/effects/<name>.json`，id 为 `<namespace>:<name>`。
`config/astrorbitsparticle/effects` 下同 id 的文件覆盖数据包版本，方便服主改参数而不动数据包。

数据包改动后先执行原版 `/reload` 让资源管理器重新扫描，再执行 `/astrorbits reload` 重建定义缓存。

定义里的 `subEffect` 指定另一个定义 id：本体正常结束时在原位置生成它一次。只展开一层，目标定义自身带 `subEffect` 时忽略，避免递归。
