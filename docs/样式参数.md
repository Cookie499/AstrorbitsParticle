# 样式参数

> 本文由 `gradlew generateStyleDocs` 从代码里的样式声明生成，改样式时重新生成，不要手改。

## common 通用字段

| 参数 | 类型 | 默认 | 范围 | 说明 |
| --- | --- | --- | --- | --- |
| `duration` | 数值 | 4 | 0.05..3600 | 特效总时长（秒），循环播放时为一个周期 |
| `loop` | 布尔 | false | - | 是否循环播放 |
| `reverse` | 布尔 | false | - | 反向播放：按 duration - age 采样；与 loop 同时启用时先按 duration 取模 |
| `subEffect` | 文本 | - | - | 子特效定义 id，不写则不生成 |
| `subEffectTrigger` | 文本 | end | - | 子特效触发方式：end 本体结束、impact 客户端粒子碰撞 |
| `emission.mode` | 文本 | burst | - | 发射方式：burst 同时出生、stream 在窗口内均匀出生、random 随机出生 |
| `emission.count` | 整数 | 200 | 1..8192 | 粒子总数 |
| `emission.window` | 数值区间 | [0, 0] | - | 发射窗口 [开始, 结束]（秒） |
| `emission.jitter` | 数值 | 0 | 0..10 | 出生时间抖动（秒） |
| `emission.lifetime` | 数值 | 4 | 0.05..3600 | 单个粒子寿命（秒），缺省等于 duration |
| `emission.lifetimeJitter` | 数值 | 0.1 | 0..1 | 寿命随机抖动比例 |
| `physics.gravity` | 向量 | [0, -9.8, 0] | - | 重力加速度（块/秒²），也可写成单个 Y 分量 |
| `physics.drag` | 数值 | 0 | 0..10 | 线性阻尼（1/秒） |
| `physics.wind` | 向量 | [0, 0, 0] | - | 风场速度（块/秒） |
| `appearance.sprite` | 文本 | minecraft:generic_0 | - | 粒子贴图 id，也可以写原版粒子定义 id（如 end_rod）；原版定义有多张贴图时按下一项选择 |
| `appearance.spriteVariation` | 文本 | particle | - | 多贴图变体选择：particle 每颗粒子随机取一张，effect 整个特效按 seed 共用一张，cycle 每 2 tick 轮换 |
| `appearance.size` | 数值 | 0.2 | 0..16 | 面片边长（块） |
| `appearance.sizeJitter` | 数值 | 0.15 | 0..1 | 尺寸随机抖动比例 |
| `appearance.sizeByAge` | 文本 | [[0,1],[1,0]] | - | 尺寸随归一化年龄的曲线 |
| `appearance.color` | 文本 | #FFFFFF | - | 基色，支持 #RRGGBB 或 [r,g,b] |
| `appearance.colorJitter` | 数值 | 0 | 0..1 | 亮度随机抖动比例 |
| `appearance.colorByAge` | 文本 | - | - | 颜色随年龄的渐变，格式 [[u,"#RRGGBB"],...] |
| `appearance.alphaByAge` | 文本 | [[0,1],[0.7,1],[1,0]] | - | 不透明度随年龄的曲线 |
| `appearance.blend` | 文本 | additive | - | 混合方式：additive 叠加，alpha 普通混合 |
| `appearance.fullbright` | 布尔 | true | - | 是否忽略世界光照 |
| `appearance.stretch` | 数值 | 0 | 0..10 | 沿速度方向拉伸的时长（秒），0 关闭；只对能给出速度的样式生效 |
| `appearance.spin` | 数值 | 0 | - | 面片自转（度/秒） |
| `visibility.viewDistance` | 数值 | 96 | 8..512 | 客户端可见距离（块） |
| `visibility.requireScene` | 布尔 | true | - | 是否必须位于演唱会场景内 |
| `visibility.boundsPadding` | 数值 | 1 | 0..64 | 包围球额外外扩（块），避免边缘被裁切 |

## astrorbitsparticle:radial_burst 放射状爆发

| 参数 | 类型 | 默认 | 范围 | 说明 |
| --- | --- | --- | --- | --- |
| `speed` | 数值 | 6 | 0..64 | 基准速度（块/秒），可写含 t 的表达式 |
| `speedJitter` | 数值 | 0.12 | 0..1 | 粒子之间的速度差异比例 |
| `originJitter` | 数值 | 0 | 0..8 | 原点抖动半径（块） |
| `axis` | 向量 | [0, 1, 0] | - | 锥形喷射主方向，只在 cone 小于 180 时生效 |
| `cone` | 数值 | 180 | 0..180 | 喷射半角（度），180 为全向 |
| `shellBias` | 数值 | 0 | 0..1 | 速度分布向快端偏移的比例 |
